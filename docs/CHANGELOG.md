## 1.6.0 — 2026-08-06

新增了逐页编辑和参数记忆，还建立了备份机制。

### 新功能

- **图文卡片：逐页编辑模式**
  自动分页适合「粘一篇长文就走」，但要精确控制每张卡片时它就挡路。
  现在多了一个「逐页编辑」：自己决定分几张、每张写什么、每张用什么背景，
  还能上移/下移/复制/删除。
  两种模式并存，而且能一键从自动分页的结果导入（不用从零敲）。
  某一页写超了会**明确标出来**（编辑框变色 + 状态栏提示），不会静默裁掉。
- **图文卡片：记住你的样式**
  比例、清晰度、背景、字号、模糊度、水印（文字/位置/透明度）、页码、封面、
  默认模式 —— 这 11 项下次打开还是你调好的样子。
  **不记你写的内容，也不记上传的图片**（内容属于隐私，图片会撑爆存储配额）。
  全部列进「设置 → 记住了我什么」，每一项都能单独忘掉。
- **备份机制**：双击 `scripts/backup.cmd` 就能把整个项目打包存一份。
  另外项目现在是 git 仓库了，能精确回退单个文件。见 [04-备份与还原.md](04-备份与还原.md)。

### 修的问题

- **卡片里的换行丢了**：输入两行文字，图上并成一行。
  原因是按标准 Markdown 规则把段落内换行当成了「软换行」——
  但这个工具的输入是用户自己排好的文字，换行是意图，不该被合并。
- **阅读设置记不住**：改了字号、每行宽度，重开插件就复原。
  原因是同一个设置有两个键名（面板存 `reading.*`、工作台存 `md:*`），
  存的和读的不是一个地方。老用户的旧值会自动迁移过来，不会丢。
- **整个界面的字看着不清楚、眼睛累**：三个 CSS 文件的字体栈都领头写了
  插件根本没打包的字体（Inter / Sora），于是一路退到宋体渲染界面文字。
  另外文件库里六十多处中文用了等宽字体（汉字在等宽里发虚），
  以及界面上有 8.5px 这种尺寸。都改了。
- **图表工具栏**：三颗按钮（View source / Copy PNG / Copy code）合成两颗，
  「看什么就复制什么」。
- **渲染图偏右**：居中被做了两次（CSS 的 auto margin + 画布的 transform）。
- **导出的网页里图片不能缩放**：现在带完整的画布（缩放、拖拽、适应画布）。
- **PDF/打印**：不再新开标签页，直接在面板里唤起打印框；
  另存为 PDF 的默认文件名现在是原文件名。
- **配置云存储时凭空上传文件**：一个失效的守卫导致粘贴被当成上传。
- **分享后跳到文件库整页错位、点不动**：两个叠加的问题，都修了。

### 顺带

- 卡片背景从 6 个加到 15 个（新增 9 个渐变，含两个径向）。
- 卡片预览可以点开看原尺寸（← → 翻页，Esc 关）。
- 文档正文字体、行高、底色都调过（纸白 #fcfcfb，不是纯白）。
- 新增第三档正文字体「圆体」。
