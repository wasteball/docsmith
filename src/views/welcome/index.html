Docsmith 装好了

Docsmith 是一套以 Markdown 工作台为核心的文档工具。舒服阅读复杂内容， 直接编辑正文和表格并核对改动；还能制作图文卡片、管理与转换文件、导出和分享。

它能替你做什么

复杂 Markdown 也读得舒服

代码、表格、数学公式、流程图和长文档都能清楚呈现；字号、字体与阅读宽度可以按自己习惯调整。

正文和表格就在阅读界面里改

不用在预览和源码之间来回切。点到哪就改到哪，表格单元格也能直接编辑，同时保留 Markdown 原文。

每处变化和评审意见都有迹可循

未保存修改、上次确认后的变化和评审意见集中在一起；可以逐处核对、撤回、定位和解决。

完成后再交付

保存回 Markdown，或导出 Word、PDF、网页；需要时还能生成分享链接、制作图文卡片和整理文件。

怎么开始

  1. 打开面板 点浏览器工具栏里的 Docsmith 图标，或点本页下方的“打开 Docsmith”。
  2. 拖一个 Markdown 文件进去 没有现成的？随便找个 GitHub 项目的 README 链接，粘进地址框也行。
  3. 想用分享功能，就连一次云存储 到「文件库 → 设置」里填上你的存储信息。支持阿里云 OSS，也支持公司现成的上传接口。 只连这一次，之后都不用管。
你的东西在你自己手里。 Docsmith 没有服务器。文件直接从你的浏览器传到你自己的云存储空间， 密钥和配置只存在这台电脑上。我们看不到，也存不了任何东西。

不想连云存储也完全能用

阅读、编辑、导出 Word / PDF / 网页，这些都不需要联网存储 —— 直接存到本地就好。 只有「生成分享链接」这一项需要先连一次。
