# 图文卡片成品示例

第一套精制案例放在：

```text
src/views/cards/examples/featured-01/
```

## 图片要求

- 推荐尺寸：`1242 × 1656`，比例 `3:4`，sRGB。
- 同一案例内所有图片保持相同尺寸。
- 支持 WebP、PNG、JPG；推荐高质量 WebP，文字边缘必须清楚。
- 文件名使用小写 ASCII 和连续两位序号：

```text
01-cover.webp
02.webp
03.webp
04.webp
05.webp
```

- `01-cover.webp` 是预览区里的案例封面。
- 图片加入、删除或改名后，必须同步修改 `manifest.js` 的 `images` 清单。
- 每张图都要填写准确的中文 `alt`，说明这一张展示什么。
- 发布前清除图片中的私密信息和不必要的元数据。
- 不要使用远程图片 URL；示例必须能够离线打开。

## 启用案例

1. 把图片复制到 `featured-01/`。
2. 打开同级的 `manifest.js`。
3. 取消案例对象的注释。
4. 按实际张数增删 `images`，保持序号连续。
5. 填写案例标题、简介和每张图的中文说明。
6. 重新加载扩展；图文卡片内容为空时，预览区会出现“查看成品示例”。

示例只用于预览，不会导入文字、套用样式或写入用户偏好。
