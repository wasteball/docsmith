# Docsmith · 文匠

一套以 Markdown 工作台为核心的浏览器文档工具：舒服阅读复杂 Markdown，直接编辑正文和表格并核对改动；也能制作图文卡片，通过文件库管理、转换和分享文件。

## 核心能力

- **舒服阅读复杂 Markdown** — 清楚呈现代码、表格、数学公式、流程图和长文档，并可调整字体、字号与阅读宽度
- **直接编辑正文与表格** — 在排好版的阅读界面中点到哪改到哪，也可随时切换到 Markdown 源码
- **核对改动与评审意见** — 集中查看未保存修改、上次确认后的变化和评审意见，逐处定位、保留、撤回或解决
- **多格式交付** — 保存 Markdown，或导出为 Word、PDF、静态网页，也可生成分享链接
- **辅助工作台** — 把文字制作成图文卡片，并通过文件库上传、分类和批量下载文件
- **本地优先** — 阅读、编辑与导出都在浏览器本地完成；只有分享或上传时才连接你配置的存储

## 安装

[查看 Docsmith 安装与使用教程](https://mp.weixin.qq.com/s/ywLOw8e2vPmV6feEv5ybDQ)

Docsmith 目前通过 Chrome/Edge 的“加载已解压的扩展”安装，不依赖 Chrome 应用商店。

## 打开 Docsmith

安装后，点击浏览器工具栏中的 Docsmith 图标即可打开。首次安装弹出的欢迎页也有“打开 Docsmith”按钮。

详细文档见 `docs/` 目录。
