# Docsmith · 文匠

> 装在浏览器边上的免费文档工作台：AI 写的文档，在这里读得舒服、改得顺手、核对得清楚。

Markdown 已经成为 AI 时代文档的事实标准 —— 你让 AI 写方案、写周报、写需求，它输出的几乎都是这种格式。可普通人的电脑上，依然没有一个能好好打开它的东西：双击一个 `.md`，跳出来的是记事本，满屏 `##`、`**`、`|---|`，里面明明有流程图和表格，全都显示成代码。

而且光「能读」还不够。AI 写得又快又多，但不一定对。你真正要做的是**核对**：这一版跟我上次看过的比动了哪几处？哪段数据我信不信？哪里有问题先记一笔，回头让它改。改完了，领导要 Word、客户要 PDF、同事要一条能点开的链接。

为此我做了 Docsmith，一个开源免费、不用注册、装完就能用的浏览器插件。跟你正在看的网页一样。

它首先是个简单好用的 Markdown 阅读器和编辑器：所见即所得、点哪改哪、代码表格公式图表都排得清楚、一键导出 Word / PDF / 网页，**不需要你懂任何 Markdown 符号**。

但真正不一样的地方是：**它不只让你读，它让你「审」。** 每处改动、每条你记下的意见，都摊在一个入口里逐条核对 —— 这是别家 Markdown 工具几乎都没做的事，也是 AI 时代最缺的一环。AI 负责生产，你负责把关，Docsmith 就是那张把关的桌子。

全程在你的浏览器里跑。没有服务器、没有账号、没有统计，你的文档从头到尾没离开这台电脑。

如果它帮到了你，欢迎给一颗 ⭐ Star。

## 核心优势

### 一、改了哪几处，一目了然 —— 别家没有的

工具栏上只有一颗「改动」按钮，点开三样东西：**还没保存的修改**、**上次确认之后的变化**（你可以随时打一个「我确认到这里了」的标记，之后你改的、AI 改的，都跟它比）、**你自己记下的意见**（读到不对的地方就在那一段旁边记一笔，表格里某个格子也能单独记）。

每条都能一键跳到原文，可以保留、撤回、标「已解决」；`Alt + ↑↓` 在改动之间来回跳；全部意见还能一次复制成整改清单发给写文档的人。

**关键在于：这些不会污染文档本身。** 意见只存在于 Docsmith 里，不写进 `.md`，也绝不出现在导出的 Word、PDF、网页里 —— 交出去的永远是干净成品。

### 二、不懂 Markdown 也能改

不用切「源码模式」，不用左右分屏。**看到哪不对，点上去就改**，跟在 飞书云文档 里改字一样。表格能插行、插列、改对齐。那些 `#`、`**` 的事 Docsmith 替你处理，你不需要知道它们是什么意思。（真想看原文长什么样，按一下按钮也能看。）

### 三、图表是真的图，断网也能画

流程图、状态图、时序图、甘特图、思维导图、四象限图、饼图，以及 AntV Infographic 信息图 —— 都**真的画出来**，能放大、拖着看、全屏、复制成图片发人；信息图断网也能正常显示。

### 四、领导要什么给什么

| 给谁 | 选什么 | 说明 |
|---|---|---|
| 要能继续改的 | **Word** | 真 Word 排版，标题表格代码块都能接着编辑 |
| 要定稿归档的 | **PDF** | 弹出打印窗口，选「另存为 PDF」 |
| 要发人看一眼的 | **网页** | 一个 `.html`，样式图表公式全打包，双击就开 |

还有一颗「复制源码」：粘进**飞书云文档**或**WPS 在线文档**，会自动认出格式排好版。

### 五、你的东西始终在你自己手里

没有服务器、没有账号、没有统计，代码全公开。只有你主动分享文件时，才连一次**你自己配置的**空间，且是浏览器直传，我们碰不到。

## 还有这些

- **看着舒服才是标准** —— 衬线 / 黑体 / 圆体三种字体，字号和行宽自由调，浅色深色主题，底色是纸白不是纯白（纯白配深字眼睛累）。
- **五种打开方式** —— 拖进来、选文件、打开整个文件夹、粘个网址加载、新建空白文档。文件夹能一键重新载入拿最新内容，正在编辑的不会被覆盖。
- **万能搜索框** —— `Ctrl + K`，记不住任何按键都没关系，想干什么就搜什么。
- **图文卡片** —— 一段文字变成一组竖版图，发小红书、抖音。四套主题、15 种背景、水印页码封面，可自动分页或逐页精编。**不懂 Markdown 也没关系**：文字框上面一排按钮（大标题、加粗、列表、引用…），选中点一下就行，跟飞书一样。
- **文件库** —— 上传（整个文件夹也行）、分类、批量拿链接、打包下载。
- **记得住你的偏好** —— 而且设置里有一栏「记住了我什么」，逐项列清楚，每项都有一颗「忘掉」按钮。

## 安装（五分钟）

没上应用商店（上架要审核要年费，而它其实不需要联网更新），所以手动装 —— 听起来吓人，实际就是**选一个文件夹**：

1. 点本页右上角绿色 **Code** → **Download ZIP**，解压。⚠️ **别放在下载夹或桌面** —— 插件要一直从这个文件夹读东西，删了或移走就打不开了，建议放 `D:\软件\Docsmith` 这种地方。
2. 浏览器地址栏输入 `chrome://extensions` 回车（Edge 输 `edge://extensions`）。
3. 打开**右上角**的「开发者模式」开关。
4. 点左上角「**加载已解压的扩展程序**」，选中刚解压出来的文件夹（要选到能看见 `manifest.json` 的那一层）。
5. 装好了。点浏览器右上角的 Docsmith 图标，面板从右边滑出来。看不到图标就点那个拼图按钮，找到它，用图钉固定出来。

配图版教程：[Docsmith 安装与使用](https://mp.weixin.qq.com/s/ywLOw8e2vPmV6feEv5ybDQ)

## 上手三十秒

**拖一个 `.md` 文件进面板**就开始了。手上没有？找个 GitHub 项目把 README 的网址粘进地址框，或者让 AI 写点什么复制过来点「新建文档」。

| 按键 | 干什么 |
|---|---|
| `Ctrl + K` | 万能搜索框（记不住别的就记这个） |
| `Ctrl + E` | 开始改 / 改完退出 |
| `Ctrl + F` / `S` | 找字 / 保存回原文件 |
| `Alt + ↑↓` | 跳到上一处 / 下一处改动 |

Windows 用 `Ctrl`，Mac 用 `⌘`；设置里的「快捷键」会按你的系统显示，不用自己换算。

## 想发链接，才需要连一次云存储

**读、改、核对、导出 Word/PDF/网页、做卡片，全都不用连任何东西**，装完就能用。只有生成**分享链接**和用**文件库**需要。

原因很实在：Docsmith 没有服务器，链接只能指向**你自己的**空间。两种连法：用公司现成的上传接口（问 IT 要个网址填上，密码留在公司服务器，你这边什么都不存），或者用你自己的阿里云（后台点几下，约十分钟）。

一步一步的大白话说明：**[怎么连你的云存储](docs/02-连接你的云存储.md)**。填完点「测试一下」看到绿色「成功」就通了，以后不用再管。

## 隐私

- **没有服务器、账号、统计。** 我们既没地方存你的东西，也没地方接收你的信息。
- **文件不经中转。** 上传是浏览器直传你自己的空间。密钥只存本机，不上传、也不进备份文件。
- **不偷偷记你读过什么。** 「最近打开的文档」缓存做过，后来整个删了（悄悄占了近 10MB），现在每次启动还会清理旧数据。滚动位置只在内存里，关掉就没了。
- **代码全公开。** 不放心可以自己看，或找个懂的朋友看。

## 它刻意不做的事

**不内置 AI**（它是审阅台，不替你写）、**不做云同步和多人协同**（文件就是你电脑上那个文件）、**不做账号登录**、**不做插件市场**、**不自带 PDF 引擎**（要额外打包中文字体，体积多好几 MB，分页还不如浏览器自己的打印，所以老实走「打印 → 另存为 PDF」）。

一件事，做到极致。

## 给想自己改的朋友

**没有安装、没有编译、不用装开发工具** —— 全是浏览器直接能读的文件，记事本改完回 `chrome://extensions` 点刷新就生效。想换名字、加减侧栏能力、加一种云存储，**只改一个文件**：`src/core/config.js`（开头有说明）。

```
src/app/        外壳：面板、侧栏、页面切换
src/core/       设置面板、偏好记忆、配色、快捷键
src/views/      markdown 工作台 / 图文卡片 / 文件库 / 说明书
src/diagrams/   图表引擎与信息图适配器
src/storage/    云存储对接
docs/           说明文档 + 改动记录
scripts/        backup.cmd —— 双击一下整个项目打包备份
```

另见 [版本号规则](docs/03-版本号规则.md) 和 [备份与还原](docs/04-备份与还原.md)。
