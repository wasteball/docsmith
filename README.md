# Docsmith · 文匠

一个浏览器扩展，让你在侧边栏读 Markdown、导出 Word/PDF/网页、一键生成分享链接。文件存进你自己的云存储。

## 功能

- **Markdown 阅读器** — 在浏览器侧边栏渲染 Markdown 文件
- **多格式导出** — 导出为 Word (.docx)、PDF、静态网页
- **云存储集成** — 支持连接你自己的云存储（WebDAV、S3 等）
- **分享链接** — 一键生成文档分享链接
- **纯浏览器端** — 所有处理在本地完成，隐私优先

## 安装

[查看 Docsmith 安装与使用教程](https://mp.weixin.qq.com/s/ywLOw8e2vPmV6feEv5ybDQ)

## 使用

安装后，点击浏览器工具栏中的 Docsmith 图标（或使用快捷键 `Alt+D`）打开侧边栏面板。

详细文档见 `docs/` 目录。
